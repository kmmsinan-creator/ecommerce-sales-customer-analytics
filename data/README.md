## Raw file

| Property | Value |
|---|---|

| Licence | CC BY 4.0 |
| Rows and columns | 541,909 rows, 8 columns |
| Period | 1 December 2010 to 9 December 2011 |
| SHA-256 | `43465a06f2ccf7c8b5bd2892bc7defb52f97487934fe93b16ae4c3936424676d` |

The cleaning script refuses to run if the raw file's checksum does not match, which proves the analysis starts from the unmodified original.

## Rebuilding the cleaned CSV

```bash
python notebooks/01_clean_data.py
```

The output has 19 columns and the same 541,909 rows, with a `line_type` and flags added. See `reports/data_dictionary.md` for every column.
