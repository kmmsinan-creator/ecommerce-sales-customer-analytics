# reports/

The analyst documentation for the project, in the order the work was done.

| File | What it covers |
|---|---|
| `02_data_audit.md` | Raw-data audit: structure, missing values, duplicates, cancellations, prices, outliers, dates. No data was modified. |
| `03_business_rules.md` | The eight line types, which rows each KPI uses, decisions on open issues, locked baseline results |
| `04_cleaning_log.md` | Generated by the cleaning script: transformations, reconciliation, validation against baselines |
| `data_dictionary.md` | Every column in the cleaned table, and which filter each KPI uses |
| `project_log.md` | A running log of steps taken and decisions made |
